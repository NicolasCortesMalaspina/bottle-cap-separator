# bottle-cap-separator

Automatic bottle cap separator with electronic and mechanical components

## Overview

A fully automated system that separates bottle caps from bottles using a combination of mechanical sorting mechanisms and electronic controls. This project demonstrates the integration of hardware engineering with software automation.
